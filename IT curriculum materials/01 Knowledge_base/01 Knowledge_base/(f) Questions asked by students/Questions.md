# (f) Questions Previously Asked by Students

> The following questions were collected from students during previous iterations of the IT project-based learning course. They are uploaded to the course knowledge base to help the chatbot anticipate common student difficulties and provide more targeted scaffolding. Questions are organized by PjBL phase and cover the five computational thinking dimensions: problem decomposition, pattern recognition, abstraction, algorithmic design, and evaluation.

---

## Project Initiation Phase

1. Our project topic "Campus Flora Guardians" feels too broad. How do I break it down into smaller, actionable tasks?

2. We want to build a plant recognition tool, but we're not sure what kind of data we need to collect first. Should we start with images, text descriptions, or something else?

## Project Design Phase

3. I'm designing the sorting logic for our plant database. How do I decide between bubble sort and quicksort? What factors should I consider?

4. How does a computer "see" an image? I don't understand how plant photos get turned into data that a model can actually process.

5. What's the difference between supervised and unsupervised learning? Which one fits our plant recognition project better?

6. We need to group similar plants together based on their leaf shapes. Is there a specific algorithm or approach for this kind of pattern matching?

## Project Implementation Phase

7. My Python code keeps throwing an "IndexError: list index out of range" when I try to access elements in a list. What does this error mean and how can I fix it?

8. I'm trying to read a CSV file of plant data using Python, but I keep getting a "FileNotFoundError." I'm sure the file exists—what should I check?

9. My if-else statements are nested five levels deep and the code is really hard to read. Is there a cleaner way to structure this logic?

10. Our model's accuracy is only around 60%. Is it because we don't have enough training data, or could there be something wrong with our data preprocessing?

11. We trained our classification model, but it performs perfectly on training data and poorly on new images. What's going on and how can we fix it?

## Project Evaluation Phase

12. We finished coding, but the program runs very slowly when we feed it a large dataset. How can we figure out which part is causing the bottleneck?

13. What does "O(n²) time complexity" actually mean in plain language? Is it always a bad thing?

14. Can someone explain recursion in simple terms? I understand the idea of a function calling itself, but I keep getting confused about when it's supposed to stop.

15. What's the difference between binary search and linear search? When should I choose one over the other?
