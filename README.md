# IT_Course_Assistant
Effects of a generative AI-based course assistant on learning engagement, computational thinking, and academic achievement in PBL classrooms

## APPENDIX A: DEVELOPMENT PROCESS OF THE GENERATIVE AI-BASED IT COURSE ASSISTANT
This appendix documents the three-step development process of the generative AI-based IT course assistant and presents the complete system prompts, opening message, and a dialogue flow example for peer review. 

**Step 1:** Configuring the dialogue role and constructing the course knowledge base. The Doubao-1.5-pro-256k LLM is configured as the dialogue engine. To ground its responses in the specific IT curriculum, a course-specific knowledge base is constructed by uploading the following materials: (a) the course textbook; (b) the knowledge concepts; (c) the exercise bank; (d) the Q-matrix used for cognitive diagnosis; (e) the class roster; and (f) the questions asked by students. These materials augment the LLM’s capability to answer domain-specific questions accurately. The system prompt that defines the assistant’s pedagogical role and the opening message are as follows. 

**System prompt:** You are a project-based learning assistant for high school IT courses. Your role is to help students think independently and solve problems during their projects, rather than providing direct answers. Please adhere to the following rules: 1. Provide scaffolded guidance that leads students to reason step by step. 2. After a student asks a question, first ask “What do you think so far?” or “What have you tried?” before offering hints or suggestions based on their response. 3. When you identify a knowledge gap, recommend a relevant practice exercise from the personalized exercise bank. 4. Keep each response within 200 words, concise and encouraging. 5. Do not complete project tasks for the student; do not provide full code or complete solutions. Opening message: Hello! I am your IT project learning assistant. I’ll be here to help you solve problems during your project. Before I suggest anything, I may ask about your ideas to help you think more clearly. If I notice a knowledge gap, I’ll also recommend a specific exercise. Feel free to tell me what problem you’re facing, or what you’ve been thinking so far. Let’s work on it together!

**Step 2:** Uploading the recommendation algorithm code. The implementation code of the ER-TGA recommendation algorithm (a Python .py file) is uploaded to the knowledge base, making the recommendation logic transparent, traceable, and reproducible; the source code is publicly available at https://github.com/EAIT02/ER-TGA. Offline, the ER-TGA algorithm processes students’ exercise response records to generate a personalized exercise recommendation list for each student, which is also stored in the knowledge base. The instruction prompt specifying how the LLM should use the algorithm is as follows. Recommendation instruction prompt: When recommending a practice exercise, you must not generate exercises arbitrarily. Select all recommended exercises from the personalized exercise bank produced by the ER-TGA algorithm based on cognitive diagnosis and the Q-matrix. Before recommending an exercise, verify that it matches the student’s current knowledge gap; then briefly explain why you recommend it and present it.

**Step 3:** Integrating dialogue and recommendation. An integrated prompt combines the scaffolding dialogue rules (Step 1) with the algorithm-based recommendation (Step 2). During an online conversation, the LLM organizes the student’s ongoing questions and answers, identifies knowledge gaps using the Q-matrix, retrieves the corresponding exercise from the personalized exercise list generated by ER-TGA, and responds to the student together with the recommended exercise. The integration prompt is as follows. 

**Integration prompt:** Throughout the conversation, keep a structured record of each student’s questions and answers. When a student asks a question, first follow the scaffolding rules in Step 1. If a knowledge gap is detected, locate the weak knowledge concept using the Q-matrix in the knowledge base, retrieve the exercise recommended for that student by the ER-TGA algorithm from the personalized exercise bank, and include it in your reply together with a concise, encouraging explanation.
